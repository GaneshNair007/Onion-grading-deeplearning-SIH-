# processed/ — Features derived from verified onion recordings

**Currently empty.**

This directory will hold spectrograms, feature tables (CSV/Parquet), and
other artifacts derived **only** from recordings in `../raw/`, generated by
the exporters in `src/acoustic/` (e.g. `python -m src.acoustic.export_features`).

Rules:

- Every processed file must reference its source recording(s) by
  `recording_id` in an accompanying metadata JSON or in-table column.
- Processed files inherit the license and redistribution status of their
  sources.
- Nothing synthetic or auxiliary may be written here — use `../synthetic/`
  or `../auxiliary/`.
