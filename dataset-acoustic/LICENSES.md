## Redistribution rules enforced by tooling

`tools/prepare_acoustic_dataset.py` refuses to pack into `parts/`:

- any file whose metadata records `redistribution_allowed: false`;
- any file in `raw/`/`processed/` lacking a metadata JSON;
- any single file larger than 100,000,000 bytes;
- files with extensions on the exclusion list (model weights, caches,
  credentials such as `.env`, `.pem`, `.key`, `.secret`).
